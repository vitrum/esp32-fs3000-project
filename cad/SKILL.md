# CAD 建模与 STL 验证

## 目标与边界

以用户明确接受的模型为基准，完成局部修改、版本保存、实际导出和独立回读验证。不得用“程序运行成功”“预览正常”或“非流形边为 0”代替完整验收。

- 不擅自安装、升级 Blender、OpenSCAD 或其他软件。优先使用现有环境；确需新增工具时先征得许可。
- 不覆盖用户认可的基准文件。修改版、外观检查版和失败输出必须明确区分。
- 将 SCAD 直接导入的 STL 与可调尺寸的参数化建模区分开；包装 `import()` 不等于逆向还原。
- Blender 按 SCAD 参数重建是另一条建模实现，不是直接执行 SCAD。说明差异并同步参数，不能冒称精确转换。
- 用户撤回某条设计路线或指定回退基准时，以最新指令为准，不能把已被拒绝的外形重新混入。

## 1. 固定输入与验收要求

1. 从用户指定的文件、模块或不合格部位开始，读取控制该几何的最小代码范围。
2. 确认输入文件、输出版本、单位、坐标轴、基准面和装配方向。不要依赖可能过时的注释。
3. 明确“上方”“迎风端”“背面”的模型坐标；必要时用截面图确认。不要把观察视角的上下误当作模型轴向。
4. 列出必须保留的尺寸：孔中心与孔径、沉孔台阶、屏幕开口、接口、卡扣配合面、传感器插槽和内部净空。
5. 分开记录外凸厚度、净空深度和壁厚。减薄外形可能直接减少电池空间，必须说明装配影响。
6. 提出一个局部可证伪的修改假设及对应检查，例如“槽切体只覆盖正向半管，因此上开槽而下壁连续”。

不要在已经能够做小修改和验证后继续无边界探索。每次实质性编辑后，立即运行最窄的有效检查，再决定下一步。

## 2. 选择建模路径

### 原样建立版本基准

若新 SCAD 仅导入用户指定的 STL，且没有变换或布尔操作：

- 使用同目录相对路径引用基准 STL，保持毫米单位与坐标不变。
- 明确告知这是网格导入版；没有新增原模型不具备的设计特征。
- 需要对应版本 STL 时，可逐字节另存基准文件，无需重新网格化。
- 用 `cmp` 或 SHA-256 确认副本一致；不能只凭文件名判断。

### 实体修改

- 优先修改拥有该尺寸或布尔操作的源模块，而非反复修补已经失败的导出网格。
- 先验证原始导入实体，再构建新增实体和切体。源模型有开口或自交时，不要继续叠加复杂布尔。
- 合并处需要真实体积重叠，不能仅点接触、边接触、共面接触或恰好相切。
- 一体式支撑可降低反复合并独立柱体的复杂度，但改变外形前必须取得用户同意。
- 将外形、内腔、支撑与孔道的布尔顺序明确化，避免挖仓切断卡扣或封住接口。
- 不使用全局缩放来修复局部薄壁；优先向允许的方向局部加料，保护装配尺寸。
- 外圆角会占用孔周平面支撑，必须复核其宽度、平整度和有效材料厚度。
- 内腔圆角会占用矩形电池的边角空间；内外风格一致不代表壁厚恒定，必须实际测量。
- 槽口方向用切体的范围控制；确认是单侧开槽、双侧贯穿，还是封闭端面，不可混淆。

### 参考模型的曲线优化

- 直接读取参考 STL，在多个纵向和横向位置采样截面，区分相似视觉与实际几何尺寸。
- 孔口、接口、卡扣和探头应有明确保护区；不能为了曲面连续而悄悄移动配合特征。
- 变形前对参与曲率变化的内外壁都提供足够、稳定的三角网格。
- 细分先在副本上检查，通过后才接受；限制轮数和局部密度，不反复加密已退化的细长三角面。
- 连续映射或正雅可比只能约束理想曲面，不能证明离散三角网格无自交、无贴面或有足够壁厚。
- 若出现褶皱、表面贴近或碎片，停止这条变形路线；不要仅靠更多细分、焊接或放宽检查继续交付。

## 3. 使用现有 Blender 执行

先确认可执行程序和版本，按当前 API 选择导入导出方法，不假设终端 Python 环境含有 `bpy`。

本项目已验证的现有程序可这样运行独立脚本：

```sh
OMP_NUM_THREADS=1 /Applications/Blender.app/Contents/MacOS/Blender \
  --background --threads 1 --python-exit-code 1 --python model_script.py
```

- 单次构建或验证用同步命令；无需启动长期后台任务。
- `--python-exit-code 1` 让 Python 失败反映到进程退出码；仍需检查是否发生原生进程崩溃。
- FAST 与 EXACT 都可能失败。根据具体阶段的验证选择，而不是认定某一种始终安全。
- 原点附近运算和单线程只能作为诊断尝试，不能保证消除旧版求解器崩溃。
- 布尔相切退化可通过小幅真实重叠消除，但不得改变约定孔径或壁厚。
- 微小容差焊接必须与单位匹配，并复查几何；过大的容差会把薄壁两侧或细边错误合并。
- 不用自动补洞、删除面、体素重网格或大范围平滑来掩盖未知问题；这些操作可能封住孔道并改变配合尺寸。
- 到达可用的局部验证门槛后停止扩展检查；失败时最多进行三次局部修复，仍失败则保留基准并说明阻塞，不输出“通过版”。

## 4. 防止空 STL 与错误导出

创建和删除临时切体可能清空主体的选中状态。导出前必须显式选中最终对象：

```python
assert len(final_part.data.polygons) > 0
bpy.ops.object.select_all(action='DESELECT')
final_part.select_set(True)
bpy.context.view_layer.objects.active = final_part
bpy.ops.export_mesh.stl(filepath=str(pending_path), use_selection=True)
```

以上导出 API 对应本项目 Blender 3.4；其他版本先检查实际 API。

- 先写入独立的临时输出路径，验收成功后再发布目标文件，避免损坏上一版。
- 非空二进制 STL 应满足：文件长度为 `84 + 50 * 三角面数量`，头部偏移 80 的小端无符号整数计数必须大于 0。
- 84 字节、面数为 0 的 STL 是空导出，不是正常的小文件。
- ASCII STL 不能套用二进制长度公式，必须按相应格式解析。
- 导出 3MF 时使用网格三角化结果或结构化模型 API；不能对非凸多边形直接使用简单三角扇。

## 5. 实际交付文件的验收门槛

必须重新导入磁盘上的最终文件，不能仅检查导出前内存对象。

### 文件完整性

- 文件存在、非空、格式可解析，三角面数量和二进制长度一致。
- 单位、外形范围和尺寸合理，无意外缩放、镜像、平移或丢失部件。
- 原样复制版本应有相同的哈希；修改版不能用相同文件名或缓存预览冒充更新。

### 拓扑与实体

- 对于用户要求的一体打印件：一个连通分量、无边界边或多面共边、有效正体积及一致朝向。
- 检查退化面、重合面、自交和内部贴面；零非流形边并不证明没有这些问题。
- 内存网格闭合而 STL 回读不闭合时，以回读结果判定失败，不能继续宣称“已闭合”。

### 关键功能尺寸

- 逐孔测量孔中心、通孔直径、沉孔直径、台阶位置和深度，不以四个相同切体代替实际结果检查。
- 孔周平面用多方向射线或截面采样检查深度范围，避免大圆角削弱支撑台。
- 探头内孔沿实际倾斜轴检查贯通；在多个截面验证槽宽、上侧开口和下侧连续材料。
- 检查接口、屏幕、卡扣配合面和电池净空是否被新增材料侵占。

### 壁厚

- 以加工方要求为下限，并留合理余量；不能把单一位置的厚度结果推广到整件模型。
- 可用 BVH 对面心和多个重心采样点沿内法线测量，记录采样数、有效命中、排除区域、最小值及薄区位置。
- 校核命中面的相对朝向，排除自命中和错误的邻面命中；对异常点做独立截面复测。
- 圆周射线避开恰好穿过网格顶点的方向，例如使用 `(segment + 0.37) / count` 的角度采样。
- 第二条壁厚射线应从实际命中点略微偏移后发出，容差按毫米单位和模型精度确定。
- 薄壁采样不能证明全局最小壁厚，也不能代替加工方审核。保留明确限制。

### 外观

- 从最终文件生成背面、内部和必要的剖面或孔槽特写，实际查看图片。
- 确认没有褶皱、裂缝、凸台突变、细碎片或内外不一致的过渡。
- 预览必须对应最终交付文件，不能沿用修复前的截图。

## 6. 项目基准与失败经验

- 当前用户指定的 V3 基准是 `aerodynamic_cycling_computer_print_reinforced.stl`。
- `aerodynamic_cycling_computer_V3.scad` 是直接导入该基准的包装文件；`aerodynamic_cycling_computer_V3.stl` 是经字节比较与 SHA-256 核对的一致副本。
- 不要假设 V3 包含后续版本的单侧开槽、一体背壳或流线变形。用户已明确回退到该基准。
- 本项目 `+X` 是屏幕侧，背面为 `-X`，探头迎风方向约为 `-Z`；旋转探头、内孔和槽口时必须使用同一局部坐标变换。
- 后续 `streamlined_back` 变形输出曾在内存检查通过、最终回读失败，同时出现极薄贴面，不能作为可靠建模起点。
- 较早的人工检查版曾有非流形边；“用户接受人工看外形”不是允许宣称可直接打印。
- 本机曾未找到 OpenSCAD；每次使用前重新确认可用工具，不把缺少渲染器的静态检查称为整机渲染通过。

## 7. 交付说明

交付时简洁列出新文件、保留的基准、实际修改和已运行检查。明确区分：

1. **基准复制版**：几何不变，说明复制一致性与版本来源。
2. **外观检查版**：仅用于人工确认形状；列出未通过项，不称为可打印版。
3. **工程验证版**：仅报告真正通过的拓扑、尺寸和壁厚检查，不扩大为加工质量保证。

有失败必须直说，不以文件生成成功掩盖。未经确认，不改变用户的软件安装限制、配合尺寸或设计方向。
