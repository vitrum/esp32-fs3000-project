# 外壳（结构件）方案分析

本文件对测量装置的两处结构件做需求分析与方案设计：
**① 探针头支架**（固定两片 FS3000，决定测量气动质量）与 **② 主机盒**（主板+屏+电池+SD）。

---

## 1. 分析目标与约束

FS3000 是**热膜式风速计**，它的读数质量几乎完全取决于周围流场，因此外壳设计的第一原则是**"少挡风、少扰流"**，其次才是防护与安装。

| 约束 | 要求 | 理由 |
|---|---|---|
| 气动保真度 | 传感器处于**自由来流区**，周边无遮挡、无回流 | 支架/罩体会直接改变局部流速与方向，引入系统误差 |
| 截面形状 | 支架截面**小且圆滑**（圆杆 ≤ Φ10mm） | 宽扁结构在风阻侧产生分离流/尾流，污染下游传感器 |
| 间距 | 两片间距 5~8 cm | 热膜互加热导致读数耦合（间距过小） |
| 防护 | 探针端至少**防雨水直击**（可放宽） | 雨滴撞击热膜会产生巨大伪计数；但防雨结构不得挡风 |
| 振动 | 探杆/支架**刚性**、无共振 | 骑行振动叠加在气流信号上，导致窗口平均失真 |
| 重量 | 探针端 ≤ 150g、主机 ≤ 300g | 前伸端重量影响操控与晃动 |
| 可维护 | 传感器可拆换、电池可换、SD 可取 | 科研装置迭代快，密封过死=报废 |
| 成本 | 优先 3D 打印/现成件 | 单件/小批量，开模不现实 |

## 2. 探针头支架：三个方案

### 方案 A —— 裸传感器 + 细杆 L 形支架（推荐起步）

```text
俯视（示意）：
      FS1      FS2
       ◇        ◇
      ╱  45°  45°  ╲
    ╱                ╲
   ╱  Φ6~8mm 圆杆支架  ╲
   ────────探杆──────────
```

- **结构**：3D 打印（PETG/PLA）一个细杆 + 两个与传感器板轮廓吻合的卡槽，传感器**完全裸露**，仅用螺丝/扎带固定。
- **优点**：流场最干净（几乎无遮挡）、制作最简单、成本最低、单臂可拆换。
- **缺点**：无防雨、无碰撞保护、传感器板易沾灰；淋雨后需擦干再测。
- **适用**：晴天科研对比测试、快速迭代。

### 方案 B —— 鱼雷形导流罩（防雨增强）

```text
侧视（示意）：
   ┌────────────────────────┐
   │   ╭────────────────╮   │
   │   │  FS1  FS2      │   │  罩体流线形，传感器风口
   │   ╰────────────────╯   │  与罩体表面平齐，前端
   └────────────────────────┘  小开口，背面全封闭
            │
         探杆
```

- **结构**：一体打印流线形（鱼雷/翼型截面）罩体，两片传感器嵌入式安装，风口开在罩体**平直段**（避开前后曲率过渡区），罩尾留排水孔。
- **优点**：防雨滴直击（只有小口进风）、外观整洁、可加装疏水格栅。
- **缺点**：罩体本身改变局部流场（需把风口放在平直段并做角度标定）、打印后处理要求高（表面粗糙会增噪）、重量略增。
- **适用**：雨天/长期户外使用，接受一次角度标定。

### 方案 C —— 分体可调支架（研究级）

```text
俯视（示意）：
     FS1             FS2
      ◇  ←─可调角── →  ◇
    ┌──┴──┐        ┌──┴──┐
    │ 小臂 │        │ 小臂 │     两臂独立，夹角可调
    └──┬──┘        └──┬──┘     （30°~60°），间距可调
      └──────┬───────┘
           探杆
```

- **结构**：公共横杆 + 两个独立小臂，小臂根部用螺栓+齿盘锁紧，角度/间距可调；传感器独立快拆。
- **优点**：可实验不同 V 角（30°/45°/60°）对测角精度的影响；单传感器可单独换新；间距可调避免互扰。
- **缺点**：结构件多、重量略增（约 +30g）、打印+装配耗时。
- **适用**：想研究"哪个 V 角最适合骑行偏航角分布"的进阶用户。

### 三方案对比（0~5 分，越高越好，主观评估）

| 维度 | A 裸件细杆 | B 导流罩 | C 分体可调 |
|---|---|---|---|
| 自由流保真度 | 5 | 3 | 4 |
| 防雨防尘 | 1 | 4 | 2 |
| 重量轻 | 5 | 3 | 3 |
| 成本低 | 5 | 3 | 3 |
| 制作简单 | 4 | 2 | 3 |
| 可调节性 | 3 | 2 | 5 |
| **综合推荐** | **★ 起步首选** | 雨天方案 | 进阶研究 |

## 3. 主机盒：三个方案

### 方案 A —— 3D 打印车把盒（推荐）

```text
前视（示意）：
   ┌──────────────┐
   │ ▓▓▓▓▓▓▓▓▓▓  │  屏幕朝上，骑行低头可见
   │  屏幕开窗    │
   ├──────────────┤
   │ [TF卡] [USB] │  侧面开口：TF卡/USB/开关
   │  电池仓(底)  │  底部可掀盖换电池
   └──────────────┘
        ═╤═  ← 码表座/上管夹具
```

- **结构**：按屏尺寸开窗打印（PETG/ASA），屏幕贴窗防水胶圈；侧面开 TF/USB/开关孔；底部电池仓独立盖。
- **优点**：定制贴合、重量可控（~180g）、迭代快（打印 2h）、可完全按你车把造型做夹具。
- **缺点**：需自己保证密封（胶圈+螺丝+防水胶）；ASA/PETG 耐候优于 PLA。
- **适用**：绝大多数用户，首推。

### 方案 B —— 现成防水接线盒（应急/雨天）

- **结构**：IP65 透明盖接线盒（约 100×68×40mm）开窗嵌屏 + 防水接头出线。
- **优点**：防水可靠（无需自研密封）、制作最快（半天）、强度高。
- **缺点**：体积重量大（~400g）、气动差（方正盒子正对来流）、外观粗糙、屏幕开窗要切割。
- **适用**：雨天长期使用、不介意重量。

### 方案 C —— 码表座式集成（比赛/长期）

- **结构**：屏幕朝车手（近垂直），底部用 GoPro/码表双转接座挂在码表架上，线束随刹车线走。
- **优点**：视野最佳（骑行中直视屏幕）、装拆 30 秒、重心贴把立气动影响小；转接件现成易购。
- **缺点**：对防水/走线要求高；屏幕朝后会溅雨；打印件受力集中需加厚。
- **适用**：想长期使用、频繁拆装、在意骑行中可视性。

### 三方案对比（0~5 分，越高越好，主观评估）

| 维度 | A 打印盒 | B 防水盒 | C 码表座式 |
|---|---|---|---|
| 气动友好 | 4 | 2 | 4 |
| 防雨防水 | 2 | 5 | 3 |
| 重量轻 | 4 | 2 | 3 |
| 成本低 | 4 | 4 | 3 |
| 制作简单 | 4 | 5 | 3 |
| 可维护性 | 4 | 3 | 5 |
| **综合推荐** | **★ 首选** | 雨天应急 | 长期/比赛 |

## 4. 材料与制作建议

| 部位 | 推荐材料 | 理由 |
|---|---|---|
| 探针头支架 | PETG / 尼龙打印 | 耐候、韧性；PLA 晒久变脆 |
| 探杆 | 碳纤维圆管 Φ8~10mm | 轻、刚、截面圆 |
| 主机盒 | PETG/ASA 打印 + 硅胶密封圈 | 耐候 + 防水 |
| 电池 | 3.7V 18650×2 + 5V 升压 | 容量 5000mAh+，满足全天测试 |
| 线束 | 26AWG 硅胶线 + 热缩管 | 耐弯折、防短路 |

**通用原则**：所有开口朝下或加挡雨檐；螺丝孔预埋热熔铜螺母（反复拆装）；探针端任何结构不得位于传感器风口正前方 5cm 内。

---

## 5. 推荐组合与验证清单

- **起步组合（推荐）**：探针头 A + 主机盒 A，全部 3D 打印，2 天可完成。
- **雨天增强**：探针头 B + 主机盒 B。
- **进阶研究**：探针头 C + 主机盒 C，验证 V 角与姿态影响。

装好后验证：
1. 静止零风读数 < 0.3 m/s（支架装配不能漏风导致自激）；
2. 固定风扇 0/15/30/45° 逐角吹，读数应接近余弦关系（偏差 >10% 查装配角度）；
3. 骑行中用手遮挡风口，读数应明显下降（验证未被车手身体尾流淹没）；
4. 颠簸路面连续 10 分钟无掉数据、无共振异响。
