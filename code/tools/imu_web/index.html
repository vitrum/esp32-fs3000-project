04 · 模拟 CdA 参数
      

      
复用项目模拟器：三秒有效功率均值 × 效率，减滚阻后除以 ½ρv³。视风需 ≥3 m/s。假定平路、稳速、静风且视风近似地速；无视风字段不拿 GPS 速度替代。CdA 是气动阻力面积，不是无量纲 Cd。
