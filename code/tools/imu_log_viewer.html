车架与前臂关系示意

选中样本的相对俯仰变化：—
右手抓握位置 手变（默认，无法判断）

抓握位置读取 CSV 可选列 grip_position（tops、hoods 或 drops）；缺失或无法识别时默认手变。现有 IMU 数据本身无法可靠判断抓握位置。前臂以假设的车把抓点为参考，虚线示意前臂 IMU 与码表之间的距离。侧视采用前臂与主机的俯仰变化差；俯视以前臂航向首样本为基准，并假设航向正向对应右肘向外。示意角度分别限幅 ±80° 和 ±55°，数值仍显示原始变化。CSV 不包含真实位置、前臂长度、车架航向、传感器安装方向或角度时间戳，距离和肘部位置不能视为实测；车架转向与航向漂移也会影响俯视结果。
