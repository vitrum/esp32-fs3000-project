# 抖音视频脚本 · AeroProbe 单车"风阻侦察兵"

> 核心一句话：几百元的单片机方案，测出骑行时"换个姿势，风阻变化多少"。
> 结构：钩子 → 是什么 → 能干什么 → 价值 → 引导。全片不涉及开发细节，聚焦项目本身。

---

## 一、20 秒极简版（主推）

### ⏱ 0–3s 钩子
- **画面**：骑车人趴低在车把上，风声呼啸
- **口播**：*"骑车趴低真能省力？到底省多少？"*
- **字幕**：趴低真的省力吗？

### ⏱ 3–8s 是什么
- **画面**：手拿起设备，屏幕亮起，风速、功率、踏频跳动
- **口播**：*"几百块钱，一块 ESP32 触摸屏加一片风速传感器，就是这台测风仪 AeroProbe。"*
- **字幕**：ESP32 触摸屏 + 风速传感器 ｜ 几百元

### ⏱ 8–14s 能干什么
- **画面**：切屏 → 蓝牙连功率计 → 数字跳动 → 写卡 → 电脑表格
- **口播**：*"实时测风速，同步读踩踏功率，蓝牙或 ANT+ 连功率计，每秒一行数据存进内存卡。"*
- **字幕**：风速 + 功率实时同步 · 存 TF 卡

### ⏱ 14–17s 价值落点
- **画面**：两种姿势数据对比图（同功率、不同速度）
- **口播**：*"同样出力，换什么姿势最省风阻、最快。"*
- **字幕**：同样的力，换个姿势快多少？

### ⏱ 17–20s 结尾引导
- **画面**：设备 + 网页模拟器，出标题"AeroProbe"
- **口播**：*"几百块的单片机，也能做点真东西。"*
- **字幕**：AeroProbe ｜ 关注看后续

**拍摄备注**
- 总时长严格 20s 内，口播约 85–95 字，节奏更快。
- BGM：快节奏科技电子乐，画面切点卡拍（约每 1.5 秒切一次）。
- 字幕：大字粗体居下半屏，`几百元`、`实时同步`、`最省风阻` 高亮放大。
- 首帧封面：趴低骑车 + 大问号，或屏幕特写 + "几百元测风阻"。

## 二、30 秒完整版（备选）

### ⏱ 0–4s 问题钩子
- **画面**：骑车人趴低在车把上，风声呼啸（广角素材）
- **口播**：*"骑车趴得越低越省力——但到底省了多少？专业风洞太贵，我们干脆自己做一个。"*
- **字幕**：趴低真能省力？省多少？

### ⏱ 4–10s 是什么
- **画面**：设备特写，手拿起，屏幕亮起显示风速、功率、踏频
- **口播**：*"几百块钱，一块 ESP32 触摸屏，加一片风速传感器，就是这台迷你测风仪 AeroProbe。"*
- **字幕**：ESP32 触摸屏 + FS3000 风速传感器 ｜ 几百元搞定

### ⏱ 10–18s 能干什么
- **画面**：手指切屏 → 蓝牙连功率计 → 屏幕数字跳动 → 数据写入 TF 卡 → 插电脑打开表格
- **口播**：*"它能实时测迎面风速，同步读取踩踏功率，用蓝牙或 ANT+ 连上你的功率计，每一秒记一行数据，存进内存卡。"*
- **字幕**：风速 + 功率实时同步 · 一键记录到 TF 卡

### ⏱ 18–24s 亮点加分项
- **画面**：环境传感器 / 姿态传感器 / GPS 模块逐个出镜，或屏幕上的温度气压界面
- **口播**：*"再配上温度气压传感器修正空气密度，GPS 记速度，绑在胸口的姿态传感器测你趴得多低。"*
- **字幕**：温度气压 · GPS · 姿态角度 全都能叠加

### ⏱ 24–28s 价值落点
- **画面**：两种姿势的数据对比图（表格/折线：功率相同、速度不同）
- **口播**：*"它只想回答一个问题——同样出力，换什么姿势最省风阻、最快。"*
- **字幕**：同样的力，换个姿势快多少？

### ⏱ 28–30s 结尾引导
- **画面**：设备 + 网页模拟器界面，出大标题"AeroProbe"
- **口播**：*"几百块的单片机，也能做点真东西。"*
- **字幕**：AeroProbe ｜ 一块板子也能搞实验 ｜ 关注看后续

**拍摄备注**
- 总时长严格 30s 内，18–24s"加分项"可删减以保时长。
- BGM：轻快科技电子乐，画面切点踩在节拍上（约每秒 1 刀）。
- 字幕：大字粗体居下半屏；`几百元`、`同步记录`、`最省风阻` 单独放大高亮。
- 首帧封面：趴低骑车 + 大问号，或设备屏幕特写 + "几百元测风阻"。
- 口播语速：全片约 115–135 字，语气"发现感"，避免念稿感。
