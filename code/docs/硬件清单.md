# 硬件清单

> 本文档列出当前「骑行气动测试仪（Aero Probe）」固件所需/支持的硬件。
> 引脚定义依据 `src/config.h`，若使用不同板卡版本请对照原理图微调。
> 这不是采购订单，仅作为硬件选型与接线参考。

## 一、主控与供电

| 硬件 | 说明 | 备注 |
|---|---|---|
| Waveshare ESP32-S3-Touch-LCD-2.8 开发板 | 主控（V1/V2 均可） | 板载 ST7789 屏 + CST328 触摸 |
| 电池 + 电源开关 | 接 PWR Key / PWR Control | 长按 5 秒关机 |

- PWR Key：`GPIO6`（电池开关按键输入，低电平=按下）
- PWR Control：`GPIO7`（拉高锁定供电，拉低断电）
- 长按关机阈值：5000 ms

## 二、显示与交互（板载）

| 硬件 | 接口 | 引脚 |
|---|---|---|
| ST7789 LCD 240×320 | SPI | MOSI=45 / SCLK=40 / CS=42 / DC=41 / RST=39 / BL=5 |
| CST328 电容触摸 | I2C | SDA=1 / SCL=3 / INT=4 / RST=2 |
| BOOT 按键 | 板上 GPIO0 | 短按打开设置页 |

## 三、传感器

| 硬件 | 用途 | 接口 / 地址 | 备注 |
|---|---|---|---|
| FS3000-1015 风速传感器 | 风速 / 空速 | I2C1（SDA=11 / SCL=10），地址 `0x28` | 原型用 1 片；完整 V 形探针用 2 片 |
| BME280 环境传感器 | 温度/气压 → 空气密度 ρ | I2C1，地址 `0x76` | 可选 |

- FS3000 采样间隔 ≥ 125 ms（数据手册响应时间）
- V 形探针：两片 FS3000 相对车头各 ±45° 张开、同点安装（`PROBE_HALF_ANGLE_DEG = 45.0`）
- 时间通过 Wi-Fi SNTP 获取，每 5 分钟重同步；无 Wi-Fi 冷启动没有真实 UTC，FIT 可能使用固定日期兜底。
- GPS/GNSS 不属于当前生产固件；移除后不提供 GPS 地速、轨迹、海拔或坡度。

## 四、无线外设（BLE）

| 硬件 | 用途 | 协议 |
|---|---|---|
| BLE 功率计 / 智能骑行台 | 功率、踏频、轮速 | Cycling Power `0x1818` / `0x2A63`，支持 FTMS |
| WitMotion WT9011DCL-BT50 姿态传感器 | 右前臂相对车架姿态 | BLE `0xFFE0` / `0xFFE1`，设备名以 "WT" 开头 |

- 轮周长默认 `2.105 m`（700×25C），按实际外胎设置（`BLE_WHEEL_CIRC_M`）
- 姿态传感器推荐绑右前臂；板载 QMI8658 始终作为车架基准。前臂姿态为实验性指标，不等同 CdA。

## 五、存储

| 硬件 | 用途 | 接口 |
|---|---|---|
| TF / microSD 卡 | CSV 日志 + FIT 导出 | SPI（SCLK=14 / MISO=16 / MOSI=17 / CS=21），1 MHz |

- 因走 SPI 且线较长，SDSPI 频率固定 1 MHz 以保稳定（`SD_SPI_FREQ_HZ`）

## 六、音频（当前已禁用）

| 硬件 | 接口 | 状态 |
|---|---|---|
| PCM5101 I2S DAC + 板载喇叭 | BCLK=48 / LRC=38 / DOUT=47 | `AUDIO_ENABLE=0`，暂不启用 |

> 音频整体关闭，避免与 BLE 无线争用；不影响传感器、日志与蓝牙功能。

## 七、需额外采购/准备的核心件（板载之外）

1. ESP32-S3-Touch-LCD-2.8 开发板 ×1
2. FS3000-1015 风速传感器 ×1（或 ×2，做完整 V 形探针）
3. BME280 模块 ×1（可选）
4. WitMotion WT9011DCL-BT50 姿态传感器 ×1（可选，支持无便携 IMU 运行）
5. microSD 卡（建议 8–32 GB）
6. BLE 功率计或智能骑行台 ×1
7. 可用 Wi-Fi 网络（用于 NTP；不是新增硬件）
8. 电池、杜邦线/排线、按需的 3.3V LDO
