## 1. 现状：板子上已有什么

依据 Waveshare 官方说明（`ESP32-S3-Touch-LCD-2.8`）：

| 已有 | 说明 |
| ---- | ---- |
| **Battery Recharge Manager 芯片** | 板载锂电池充电管理，MX1.25 2PIN 电池接口，支持 **充/放电** |
| **Charging 指示灯** | **充电时亮、充满灭**（未接电池时状态不确定） |
| **Power 指示灯** | 电源指示灯 |
| **电池供电控制按键** | 需固件实现（`PWR Key=GPIO6` / `PWR Control=GPIO7`，见 `power_key.cpp`） |
| I2C 板载地址 | 仅 `0x51(RTC) / 0x6B(IMU) / 0x7E(触摸)` —— **没有电量计** |

**关键判断**：

- **充电管理已由硬件完成**（恒流/恒压、充满截止），固件**不需要也不可能**去"控制充电"。
  固件能做的是：**读电量、读充电状态、低电量保护**。
- **没有电量计 IC**，因此电量必须**自己采**——ADC 读电池分压是最低成本路线（§4）。
- 项目已有 `PowerKey`（电源锁定/长按关机）与 `CsvLogger::stop()`（安全关文件），
  低电量保护可以直接复用这套"先保存、再断电"的流程。

## 2. 需求与设计原则

| 编号 | 需求 | 说明 |
| ---- | ---- | ---- |
| B1 | **实时电量显示** | 屏幕显示电量百分比（大字/图标），网页 `/ws` 帧带电量 |
| B2 | **充电状态显示** | 屏幕上区分"充电中 / 已充满 / 放电中" |
| B3 | **低电量预警** | 低于阈值时提示（声音/闪屏/日志），提醒结束测试 |
| B4 | **低电量保护** | 极低电量时**先停记录、安全关文件、再断电**，避免数据损坏 |
| B5 | **记录可用性** | 电量进入 CSV meta 或日志，便于事后核对"哪段数据可能不完整" |
| B6 | **续航预估** | 用放电速率估算剩余时间，供现场判断是否还能跑完一轮测试 |

**设计原则**：

- **不引入昂贵器件**：优先 ADC 分压（几毛钱电阻）；电量计 IC 视为可选升级。
- **不改充电硬件**：充电由板载管理芯片负责，固件只做监测与保护。
- **掉电优先保数据**：与 [`plan/README.md`](./README.md) §2.4 "先 flush/close 再断电"一致。

## 3. 电量采样方案对比

| 方案 | 成本 | 精度 | 需要额外 IO | 优点 | 缺点 |
| ---- | ---- | ---- | ----------- | ---- | ---- |
| **A. ADC 分压**（每板推荐） | **≈0.2 元**（2 个电阻 + 1 个 0.1µF） | ±3~5%（需标定） | 1 个 ADC 脚 | **最省、零依赖、立即可做** | 受 ADC 线性/REF 误差影响，需软件校准 |
| B. 库仑计 IC（如 MAX17048/BQ27441） | ~10~20 元 | 高（±1~2%，SOC 曲线） | 1 条 I2C + 中断脚 | 电量百分比直接给、精准 | 多花钱、多占 I2C 地址、需驱动 |
| C. 只读 CHRG/STDBY 指示 | 0 元（若脚可引出） | 只能判断"在充电/充满" | 视引线 | 判断充电状态最直接 | **不能测电量** |
| D. 电池内建保护板输出 | 视电池 | 低 | — | 无 | 不适用 |

**结论**：**A（ADC 分压）+ C（充电状态）组合**，总增量成本 **≈0.2 元**，
满足 B1~B6 全部需求。电量计 IC（B）作为**可选升级**，并**与 I2C 分路规划统筹**（见 `plan/i2c-bus.md` §5）。

> 若将来确实要"精确 SOC + 剩余分钟数"，再上 MAX17048（I2C 地址 `0x36`，不与现有 `0x28/0x76/0x51/0x6B/0x7E` 冲突），
> 但**当前阶段用 ADC 分压即可**，不为此增加预算。

## 4. 推荐方案：ADC 分压 + 采样管脚

### 4.1 电路

```text
  VBAT (电池 +，MX1.25 座，约 3.0~4.2V)
     │
    [R1] 100kΩ
     ├────────────── ADC 采样脚（ESP32-S3 ADC1 某通道）
     │
    [R2] 100kΩ        （1/2 分压 → 2.1V 满电，落在 ADC 量程内）
     │
    GND
     └─ 0.1µF 并联到 GND（滤除电机/PWM 噪声）
```

- 分压比 `R2/(R1+R2)`，**2 选 1/2 或 1/1.5~1/2 区间**，满电 ≤ 2.2V（ESP32 ADC 建议参考 2.5V/3.3V 顶），
  留裕量避免超量程。
- **ADC 脚选择**：优先 **ADC1**（ADC1 在 Wi-Fi 开启时仍可用，ADC2 与 Wi-Fi 冲突）。需查板卡剩余 ADC1 引脚。
- **滤波**：0.1µF + 软件中值/滑动平均，降低负载瞬态（LCD 背光、Wi-Fi 发射）造成的抖动。

### 4.2 电池电压 → 电量映射

锂电池放电曲线**非线性**，直接用"线性百分比"误差大。建议**分段线性查表**：

| VBAT (V, 单节) | 估计 SOC |
| -------------- | -------- |
| 4.20 | 100% |
| 4.05 | ~90% |
| 3.95 | ~75% |
| 3.85 | ~60% |
| 3.75 | ~40% |
| 3.65 | ~20% |
| 3.55 | ~10% |
| 3.40 | ~5% |
| 3.20 | 0%（保护截止附近） |

> 这些是典型 4.2V 单节锂电的**参考曲线**，实际会随放电倍率、温度、电池老化偏移。
> **必须实测标定**（§8），并允许用户设置"低电量阈值"。

### 4.3 采样节奏

- **每 2~5 秒**采一次（不必高频），多次采样取中位数；
- 电压经历负载瞬态，建议**取"带载稳态值"**而不是瞬时值；
- **充电时**电压会偏高（CV 阶段接近 4.2V），此时 SOC 估计**不可信**——充电时应显示"充电中 / 电压 xx"，**不显示 SOC 百分比**，或标 `charging=true` 供 UI 区分。

## 5. 充电状态检测（CHRG 指示灯 / 引脚）

三种可行手段，按可获得性取舍：

| 手段 | 做法 | 说明 |
| ---- | ---- | ---- |
| **① 读出 CHRG 引脚**（最佳） | 若充电芯片的 CHRG/STDBY 输出可从板子引出到某 GPIO | 直接区分"充电中/充满/放电"；需查原理图确认该脚是否可访问 |
| ② 电量推断 | 观察"电压持续上升 / 稳定在 ~4.2V"判定在充电 | 免硬件，但慢、易误判 |
| ③ 不检测 | 只看电压 | 最省事，但用户不知道是否在充电 |

**推荐**：优先尝试 ①（查原理图/飞线引出 CHRG 到空闲 GPIO，带上拉输入），
若不可行退到 ②（电压趋势 + 满电判定）。

> **注意**：官方说"未接电池时 Charging 指示灯状态不确定"——所以**充电状态检测在无电池时要能判为"未知"**，
> 不能把"灯亮"当唯一真相。电量读数也应能识别"未接电池"（电压 < 2.8V 或波动异常 → `batteryPresent=false`）。

## 6. 低电量保护与掉电安全

### 6.1 分级阈值（建议，可配置）

| 级别 | 阈值（单节，参考） | 动作 |
| ---- | ------------------ | ---- |
| 正常 | > 3.60V（~15%） | 正常运行 |
| **预警** | ≤ 3.55V（~10%） | 屏幕提示"电量低"、可选提示音、写日志 `LOW_BATTERY`；记录继续 |
| **保护** | ≤ 3.45V（~5%） | **主动 `recorder.requestShutdown(now)`**：flush + 关闭 CSV/FIT，然后断电 |
| 硬截止 | 电池保护板 ~3.0V | 硬件兜底（可能丢最后数据，故尽量在保护级之前主动关） |

### 6.2 动作顺序（复用现有流程）

```text
检测到保护级
  → LED/屏幕提示 + 日志
  → csvLogger.stop() / recorder.requestShutdown()   // 先安全关文件
  → lcd.saveDashboardSettings()                     // 保存设置
  → powerKey.shutdown()                             // 拉低 GPIO7 断电
```

> 这条链 **`PowerKey` + `CsvLogger::stop()` 已存在**（见 `main.cpp` 的 `shutdownPending` 分支），
> 本规划只是**新增一个触发源：低电量**，与"长按 5 秒关机"共用同一套安全关闭流程。

### 6.3 防止误关机

- 保护级阈值需要**去抖**（连续 N 秒低于阈值才动作），避免大电流瞬间压降误触发；
- **充电中不触发低电量保护**；
- 记录未开启时也可触发电量保护（仅提示 + 断电）。

## 7. 软件集成（模块接口与 UI/Web 展示）

### 7.1 新增 `src/battery.{h,cpp}`

```cpp
// battery.h —— 电池电压/电量/充电状态
enum class ChargeState : uint8_t { Unknown, Discharging, Charging, Full };

class Battery {
public:
  bool begin(int adcPin, int chrgPin = -1);   // 传入采样脚与可选 CHRG 脚
  void tick();                                // 非阻塞：按节奏采样、滤波、更新状态

  bool present() const;                       // 是否检测到电池（电压合理）
  float volts() const;                        // 电池电压 (V)
  float percent() const;                      // 0~100（充电时为 -1 表示不可信）
  ChargeState chargeState() const;            // 充电状态

  bool lowBattery() const;                    // 进入预警级
  bool criticalBattery() const;               // 进入保护级（用于触发关机）
  int  minutesRemaining() const;              // 剩余分钟估算（可为 -1 未知）

  void setLowThreshold(float v);              // UI/配置可改
  void setCriticalThreshold(float v);
};
```

- ADC 读取走 `analogReadMilliVolts()`（ESP32 Arduino 自带校准），**不要用裸 `analogRead`**，
  能显著减小 REF 误差；
- `tick()` 内部做**中值滤波 + 慢速滑动平均**，只在值稳定时更新对外读数。

### 7.2 `main.cpp` 集成

```cpp
Battery battery;

void setup() {
  powerKey.begin();
  battery.begin(PIN_BAT_ADC, PIN_BAT_CHRG);   // 新增 config 宏
}

void loop() {
  powerKey.tick();
  battery.tick();

  // 低电量保护：与长按关机共用 shutdown 流程
  if (battery.criticalBattery() && !shutdownPending) {
    shutdownPending = true;
    recorder.requestShutdown(millis());
  }
  if (shutdownPending && lcd.saveDashboardSettings()) {
    powerKey.shutdown();
    return;
  }
  // ... 现有采样/记录/UI 逻辑 ...
}
```

## 8. 校准与验证

### 8.1 校准步骤

1. 用**万用表实测**电池电压 `V_meter`（同时 `Battery.volts()` 记录 `V_adc`）；
2. 在多个电压点（4.2/3.9/3.7/3.5/3.3V）各取一组，拟合 `V_meter = a·V_adc + b`；
3. 把 `a/b` 写入固件（或存 Preferences），**纠正 ADC 分压误差**；
4. 用实测放电曲线替换 §4.2 的参考表（至少覆盖本项目常用电流使电池放电到 3.3V 的整段）。

### 8.2 验证清单

- [ ] 满电 / 半电 / 低电三档，屏幕百分比与万用表误差 < 5%；
- [ ] 充电时显示"充电中"，拔充电器后回到"放电中"；充满后显示"满"；
- [ ] 不接电池时读数为"未知/无电池"，**不误显示 0%**；
- [ ] 负载变化（开 Wi-Fi / 点屏 / SD 写入）时电量读数**抖动 < 0.1V**；
- [ ] 模拟低电量（可调阈值测试）→ 触发保护 → 数据文件完整可读、无损坏；
- [ ] 长时间（≥1 小时）采样无漂移、无 NaN。
