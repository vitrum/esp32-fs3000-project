The FS3000 measures wind speed only; it does not provide temperature. A BME280 can provide temperature for air-density calculation. CdA is an estimate assuming calm air, level ground, and steady speed. Apparent wind is approximated as ground speed; one wind sensor cannot measure true ground speed or wind direction.

Sensor Simulation

Power Meter

BLE inputs are separate from virtual sliders. Connect BLE injects a connection; the screen picker performs a timed scan and confirmation. No ANT support.

Sampling Controls

Sampling advances uptime and the 3-second CdA power average. It does not start CSV recording; use the simulated web controls below.

GPS / Sensors (simulated)

GPS page shows UTC / UTC+8, coordinates, SAT / HDOP, altitude and speed. Logs use fresh GPS speed; dashboard CdA still approximates ground speed from wind.

Wi-Fi / SD (simulated)

Simulated Web Controls / CSV

Requires simulated Wi-Fi connection. One download, at most 1 KiB per 20 ms; SD busy retries for up to 5 seconds. CSV has the firmware columns and source IDs 0 / 1 / 3. Demo audio only changes playback state, not browser sound.
